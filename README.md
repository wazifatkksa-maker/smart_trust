# SMARTTRUST — ثيم سلة (Twilight)

ثيم معماري فاخر لمتجر أنظمة المنازل الذكية (KNX · Zigbee · Control4)، مبني على محرك Twilight (Twig) ومتوافق مع هيكل Theme Raed الرسمي.

## التشغيل

```bash
pnpm install              # أو npm install
pnpm run production       # يبني public/ (CSS + JS + الصور)
salla login
salla theme preview --with-editor
```

للربط بلوحة شركاء سلة:
1. ارفع المجلد إلى مستودع GitHub خاص.
2. من Partners Portal اختر: My Themes ← Create theme ← Import an Existing Theme.
3. اختر المستودع.

## العمل على VS Code كمتجر محلي (بدون سلة)

المشروع يعمل محليًا كمتجر كامل ببيانات تجريبية، باستخدام **نفس** قوالب Twig وCSS وJS التي تُرفع إلى سلة. أي تعديل تراه محليًا هو التعديل الذي سيظهر في المتجر الحقيقي.

```bash
pnpm install        # مرة واحدة
pnpm run dev        # http://localhost:3000  — يعيد التحميل تلقائيًا عند الحفظ
```

- **كل الصفحات:** افتح `http://localhost:3000/__dev/routes`. منها:
  - الرئيسية
  - المنتجات والتصنيفات
  - صفحة المنتج (13 منتجًا)
  - السلة، والسلة الفارغة، وصفحة الشكر
  - صفحات KNX وZigbee وControl4
  - من نحن، وتواصل معنا
  - المشاريع ومقالاتها
  - الحساب والطلبات
  - الماركات
  - البحث
- **النسخة الإنجليزية (LTR):** أضف `?lang=en` لأي رابط.
- **من VS Code:** شغّل Terminal ← Run Build Task (أو Ctrl/Cmd+Shift+B).

### تصدير صفحات HTML مستقلة

```bash
pnpm run export     # يُنشئ مجلد site/ — 49 صفحة HTML تعمل بفتحها مباشرة أو برفعها على أي استضافة
```

مفيد لعرض المتجر على العميل أو مشاركته قبل ربطه بسلة.

### أين أعدّل ماذا؟

| أريد تعديل… | الملف |
|---|---|
| الألوان والخطوط والمسافات | `src/assets/styles/_tokens.scss` |
| شكل الهيدر / الفوتر | `src/views/components/header|footer/*.twig` + `_header.scss` / `_footer.scss` |
| أقسام الرئيسية | `src/views/components/home/*.twig` + `_home.scss` |
| بطاقة المنتج | `src/assets/js/partials/product-card.js` + `_product-card.scss` |

| البيانات التجريبية (منتجات، قائمة، سلة) | `dev/mock.js` |

### ملاحظة مهمة

مجلد `dev/` للمعاينة المحلية فقط، ولا يُستخدم داخل سلة:
- **`dev/salla-shim.js`:** بديل مبسّط لمكوّنات سلة، مثل قائمة المنتجات وزر السلة والكمية والتصفية وملخص السلة.
- **في المتجر الحقيقي:** تأتي هذه المكوّنات من سلة نفسها، فيختلف شكلها الداخلي قليلًا وتكون وظائفها كاملة.
- **الشارة الصفراء:** شارة «PREVIEW · MOCK DATA» في الزاوية تذكير بأن البيانات تجريبية.

## قرارات مؤجلة (أصبحت إعدادات)

- **نموذج KNX:** إذا حُدد «رابط استقبال نموذج KNX» يُرسل الطلب عليه (POST multipart، مع ملف المخطط). وإذا لم يُحدد، يُفتح واتساب برسالة جاهزة. الرقم يؤخذ من إعداد «رقم واتساب»، أو من رقم واتساب المتجر.
- **توافق الأنظمة:** يُستنتج من وسوم المنتج واسمه وعنوانه الترويجي. تكفي كتابة KNX أو Zigbee أو Control4 في الوسم.
- **عرض السعر:** يظهر «اطلب عرض سعر» بدل زر السلة في حالتين:
  - سعر المنتج صفر.
  - العنوان الترويجي يحتوي كلمة «عرض سعر». الكلمة قابلة للتعديل من الإعدادات.
- **الصور:** كل صور الواجهة إعدادات قابلة للاستبدال. الصور المرفقة معاينات ثلاثية الأبعاد مؤقتة، تُستبدل بالتصوير الفعلي.
- **صفحات KNX وZigbee وControl4 و«من نحن» و«تواصل معنا»:**
  1. أنشئ الصفحة في سلة.
  2. ضع رقمها في «الصفحات التعريفية» داخل إعدادات الثيم.
  3. ستظهر الصفحة بالتصميم الخاص تلقائيًا.
- **المشاريع:** تُدار من المدونة، عبر تصنيف باسم «المشاريع».

## ملاحظات قبل النشر

- **مفاتيح المكوّنات:** مفاتيح `key` في twilight.json مولَّدة كـUUID ثابتة. إن طلبت لوحة الشركاء مفاتيح منها، استبدلها قبل النشر الأول.
- **لون المتجر الأساسي:** يُفضّل ضبطه في إعدادات سلة على `#111214` حتى تتسق مكونات سلة الداخلية (نافذة الدخول، الأزرار) مع الثيم.
- **حجم app.css:**
  - يبلغ ~560KB، منها ~450KB أنماط مكوّنات سلة من `@salla.sa/twilight-tailwind-theme` (مثل Raed)، و~70KB لأنماط الثيم.
  - بعد الضغط يصبح ~75KB.
  - حجم المستودع الإجمالي (src + public) أقل من 2MB، وهو حد الثيمات الخاصة.
- **`|raw`:** يُستخدم فقط لمحتوى المحرر في سلة (وصف المنتج، محتوى الصفحة، نص المقالة)، بنفس نمط Theme Raed.
- **غير مشمول في هذه النسخة:**
  - النشرة البريدية: لا توجد API رسمية لها في Twilight.
  - طبقات مخطط KNX التفاعلية: مؤجلة إلى أن يتوفر مخطط حقيقي.
